# 🌦️ WeatherNow Pro 
 
# 📌 Overview

**WeatherNow Pro** is a modern weather forecasting web application built using **HTML5, CSS3, and JavaScript**. It provides real-time weather updates, current location weather detection, hourly forecasts, 5-day weather forecasts, dynamic weather backgrounds, animated UI effects, and a glassmorphism-inspired design.

The application uses the **OpenWeatherMap API** to fetch live weather data and automatically changes the background video and weather visuals based on current weather conditions. The project demonstrates API integration, asynchronous JavaScript, responsive UI design, DOM manipulation, and dynamic weather visualization.
